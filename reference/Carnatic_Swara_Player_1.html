    Which letters do I write for the swaras?

    S R G M P D N are the swaras. Variants are R1 R2 R3, G1 G2 G3, M1 M2, D1 D2 D3 and N1 N2 N3.

    How do I write the lower and upper octaves?

    Write a lower-octave note as s or S. (shown as Ṣ), and an upper-octave note as S' (shown as Ṡ). Ṣ and Ṡ are the two octaves. A lower Pa after a note is written P..

    How do I hold a note, add a rest or mark a tāla bar?

    A comma (,) holds a note for one beat and a semicolon (;) for two. A hyphen (-) is a rest, and a bar (|) marks a tāla bar.

    How do I put several notes in one beat?

    Notes written together, such as SRG, share one beat.

    Can I change the tempo while it plays?

    Yes. Tempo changes apply straight away.

    How do I choose a string for a note?

    Write @ and a string number. S@2 plays that one note on string 2, @3 sets string 3 for the notes after it, and @0 returns to the default string.

    How do I add hammer-ons, slides and other ornaments?

    Ornaments go just before a note: h for hammer-on, p for pull-off, / for slide up, \ for slide down, ~ for shake and * for gamaka. For example, GhP is a hammer-on from G to P.

    How do I add lyrics?

    Start a line with [SWARA1] followed by its notation, then put [SAHITYA1] and the words on the next line. The words show on the stage above the falling notes while that line plays, and the markers are not counted as notes.
